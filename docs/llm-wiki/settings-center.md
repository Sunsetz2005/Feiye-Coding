# 设置中心

`SettingsPage` 是 Sunsetz 的全页设置外壳。参考截图只用于校准侧栏密度、选中状态、内容宽度和卡片层级；栏目名称、数据来源与能力边界由 Sunsetz 自己的 Host 和 Runtime 决定。

## 栏目注册表

`src/lib/settingsRegistry.ts` 是设置导航和搜索的单一注册表。当前只登记已有真实页面：

- 常规。
- 外观。
- 账户。
- 已归档会话。
- 扩展。
- CLI / Runtime。
- 关于。

新增栏目必须同时具备真实页面、数据读取和必要的保存命令，才能进入注册表。语音、智能快照、浏览器、电脑控制、Hooks、Git、Environment、Worktree 和快捷键编辑等未完成能力不得作为占位入口出现。

每个栏目登记标题、分组、图标和当前真实配置项的搜索关键词。搜索必须能通过具体配置名称定位栏目，例如“默认权限”定位常规、“MCP”定位扩展、“CLI 路径”定位 Runtime；搜索不到时显示本地化空状态，不保留空分组标题。

## 视觉与交互

- 左侧保持中性系统侧栏；当前栏目用整行中性背景，不使用 coral 边框或品牌渐变。
- 右侧使用单一滚动容器和受限内容宽度；标题、分组标题、设置卡片按参考图的紧凑层级排列。
- 设置卡片使用细边框和实体表面，不叠加装饰性光晕或厚阴影。
- 搜索、返回和栏目均保留原生按钮/输入语义、可见焦点和按压反馈。
- 当前栏目使用 `aria-current="page"`；搜索输入有可访问名称；空结果通过 `role="status"` 宣告。
- 900×600 仍保持左右分栏且无横向溢出；更窄布局另行设计，不能通过压扁控件伪装完成。

## 多语言

栏目标题、关键词来源和空状态全部使用 `createT(locale)` 的完整目录。新增或修改设置文案时必须同步英文、简体中文和繁体中文；不得在注册表中写死面向用户的单语言字符串。
