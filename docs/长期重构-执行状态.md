# Sunsetz 全工作台长期重构执行状态

本文是长期重构的执行入口。产品行为仍以 `docs/llm-wiki/` 下的权威说明和代码为准；参考截图只提供可见交互事实，不覆盖 Sunsetz 的 Host、Runtime、品牌和信息架构。

## 阶段门禁

每一阶段必须依次完成：

1. 协议和持久化兼容检查。
2. TypeScript 类型检查与前端测试。
3. UI 生产构建与 Rust 测试。
4. 目标尺寸截图回归。
5. 键盘、焦点、缩放和系统辅助偏好检查。
6. 相关平台手动验收。
7. 权威文档同步。

未满足全部门禁时，阶段状态只能是“进行中”或“受限”，不得标记为完成。

## 当前状态

产品内核已改为 Sunsetz 内建 agent loop（`src-tauri/src/agent_loop.rs`）。默认不再 spawn `grok agent stdio`；Grok ACP 适配器保留在 `runtimeBackend=grok_acp` 显式开关后。Host 工具现为可信项目根内的 `read_file`、`list_directory`、`grep`、`write_file`、`search_replace`、`run_command`，以及父会话 `spawn_agent` / `agent_output` / `kill_agent` 和 `command_output` / `wait_commands` / `kill_command`。子代理是进程内 `run_turn`，深度 1。写入、替换和命令走现有权限条，`AcceptEdits` 不自动放行命令，相同工具加相同参数连续 3 次会被打断，逃出根目录/拒绝/Stop 无副作用。父会话 `run_command` 可后台托管；Stop 不杀掉已批准的后台命令。父回合只 join 本轮后台 child；Steer/Stop 只取消本轮 child；后台子代理或后台命令结束后 Host 可开一轮无用户气泡的 wake turn。前台命令墙钟 15 分钟；模型 SSE 按 `streamStallSeconds` 空闲失败，没有 2 分钟总超时。工具轮次用尽后成功结束，可再发送。显式 Skill 从库存已信任目录装载有界 `SKILL.md` 到该轮提示，journal 只留 token；不依赖 grok 二进制，GROK_HOME 不是产品内核。已审阅 Memory pack 可显示在输入器并显式注入该轮提示。信任项目会有界读取 `AGENTS.md` / `Sunsetz.md` / `.sunsetz/instructions.md` / `CLAUDE.md`。单轮最多 16 次工具调用。默认内核在 `/compact` 或占用/硬顶阈值触发时摘要模型上下文，可见 journal 不改写。`run_command` 可按 `sandboxProfile` 使用 Linux bubblewrap、macOS sandbox-exec 或 Windows AppContainer。内核可 `list_skills` / `view_skill` / `skill_save`，并有独立的自动记忆契约。`schedule_task` 写入现有已安排账本；默认内核到期由 Host 点火。设置向导是登录 Sunsetz 或跳过进入工作台，不再把 grok CLI、xAI 密钥或本机 Open Connector 当作首屏门槛。这不是整阶段完成。

## 自动化入口

2026-09-17 已恢复视觉门禁：视觉 TSX 夹具纳入 `pnpm typecheck`，行为和几何命令及 Darwin 像素命令均为 45/45；42 张像素基线中 41 张因当前产品事实变化而重生成，并在三尺寸、三主题及各专题中逐张人工审阅，像素阈值仍为 100。

- `pnpm verify:contracts`：检查前端 invoke 与 Tauri 注册命令、前端监听事件与 Host 发射事件是否匹配。
- `pnpm test:coverage && pnpm coverage:audit`：生成前端覆盖率并阻止相对阶段一基线超过 0.25 个百分点的回退。
- `pnpm coverage:changed`：按 80% 行、70% 分支强制检查改动代码覆盖率；本轮当前实测为 93.75% 行、80.65% 分支。
- `pnpm coverage:rust && pnpm coverage:rust:audit`：Rust 行覆盖率当前实测 44.39%，通过 37.62% baseline gate；最终覆盖率目标仍单独追踪。
- `pnpm test:visual`：运行三种尺寸、三种主题的空工作台与资源面板截图回归，覆盖上下文摘要、计划模式、唯一计划决策入口、侧栏预览和菜单，并执行 200% 基本可操作性检查。
- `pnpm test:visual:ci`：在 Linux 执行同一行为和几何矩阵，但忽略仅适用于 Darwin 的像素基线。
- `pnpm test:visual:update`：仅在人工确认视觉变化符合参考事实后更新基线。
- `scripts/windows-native-smoke.ps1`：CI 中启动真实 Windows Tauri 窗口，并通过 WebView2 CDP 验证窗口工作区边界、面板生命周期、焦点恢复和 Space 键路径；产物包含原生窗口与资源面板截图。
- `scripts/windows-stage1-manual.ps1`：物理 Windows 上逐项记录 200% 缩放、完整键盘与焦点、面板生命周期、窄窗口和三主题证据；任何 FAIL 返回非零状态。
- `pnpm verify:stage0`：阶段零前端与视觉门禁；Rust 测试仍单独在 `src-tauri` 运行。

截图和通用 200% 检查使用浏览器降级路径。macOS 调试 `.app` 已补充 Retina 2× 原生窗口证据，Windows CI 已补充云端原生窗口自动证据；两者都不替代 Finder、系统权限或 Windows 实机手动验收。`coverage-policy.json` 中的全仓 80% 行 / 70% 分支是最终目标，不是当前全仓覆盖率结论。

本轮成熟能力迁移的安全边界、技术债和平台限制见 [`docs/llm-wiki/runtime-migration-v1.md`](llm-wiki/runtime-migration-v1.md)。在 Windows 物理机验收前，本轮只能标记为“自动门禁通过、发布受限”。
