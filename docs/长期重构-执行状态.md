# Sunsetz 全工作台长期重构执行状态

本文是长期重构的执行入口。产品行为仍以 `docs/llm-wiki/` 下的权威说明和代码为准；参考截图只提供可见交互事实，不覆盖 Sunsetz 的 Host、Runtime、品牌和信息架构。

## 阶段门禁

每一阶段必须依次完成：

1. 协议和持久化兼容检查。
2. TypeScript 类型检查与前端测试。
3. UI 生产构建与 Rust 测试。
4. 目标尺寸截图回归。
5. 键盘、焦点、缩放和系统辅助偏好检查。
6. 相关平台手动验收。
7. 权威文档同步。

未满足全部门禁时，阶段状态只能是“进行中”或“受限”，不得标记为完成。

## 自动化入口

- `pnpm verify:contracts`：检查前端 invoke 与 Tauri 注册命令、前端监听事件与 Host 发射事件是否匹配。
- `pnpm test:coverage && pnpm coverage:audit`：生成前端覆盖率并阻止相对阶段一基线超过 0.25 个百分点的回退。
- `pnpm coverage:changed`：按 80% 行、70% 分支强制检查改动代码覆盖率；阶段一当前实测为 80.39% 行、86.44% 分支。
- `pnpm coverage:rust && pnpm coverage:rust:audit`：记录 Rust 覆盖率基线；阶段一保持 audit-only。
- `pnpm test:visual`：运行三种尺寸、三种主题的空工作台与资源面板截图回归，覆盖上下文摘要和计划模式，并执行 200% 基本可操作性检查。
- `pnpm test:visual:ci`：在 Linux 执行同一行为和几何矩阵，但忽略仅适用于 Darwin 的像素基线。
- `pnpm test:visual:update`：仅在人工确认视觉变化符合参考事实后更新基线。
- `scripts/windows-native-smoke.ps1`：CI 中启动真实 Windows Tauri 窗口，并通过 WebView2 CDP 验证窗口工作区边界、面板生命周期、焦点恢复和 Space 键路径；产物包含原生窗口与资源面板截图。
- `scripts/windows-stage1-manual.ps1`：物理 Windows 上逐项记录 200% 缩放、完整键盘与焦点、面板生命周期、窄窗口和三主题证据；任何 FAIL 返回非零状态。
- `pnpm verify:stage0`：阶段零前端与视觉门禁；Rust 测试仍单独在 `src-tauri` 运行。

截图和通用 200% 检查使用浏览器降级路径。macOS 调试 `.app` 已补充 Retina 2× 原生窗口证据，Windows CI 已补充云端原生窗口自动证据；两者都不替代 Finder、系统权限或 Windows 实机手动验收。`coverage-policy.json` 中的全仓 80% 行 / 70% 分支是最终目标，不是当前全仓覆盖率结论。
