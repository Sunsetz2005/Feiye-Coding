# Sunsetz 工作台视觉验收记录

## 自动截图基线

Playwright 当前覆盖五组证据：

- 空工作台：900×600、1200×800、1600×1000 × 深色、浅色、高对比度，共 9 张像素基线；
- 资源面板打开：同一三尺寸三主题矩阵，共 9 张像素基线，并检查面板关闭后内容卸载和顶部栏触发按钮恢复焦点；
- 上下文摘要：三个目标尺寸各 1 张深色像素基线，并检查摘要宽度和 viewport 碰撞；
- 计划模式：三个目标尺寸各 1 张深色像素基线，并检查其位于访问权限右侧、上方无重复计划条、悬停显示关闭态以及点击后退出；
- 计划确认：三个目标尺寸各 1 张深色像素基线，并检查全页面只有底部一处“计划待审阅”和一组批准入口，消息卡片与右侧资源计划均为只读中性状态；
- 侧栏预览：真实 `SidebarNavigator` 测试夹具在三个目标尺寸分别覆盖任务悬停预览和项目键盘聚焦预览，共 6 张深色像素基线，并检查 viewport 碰撞和 310px 宽度上限；
- 菜单：三个目标尺寸分别覆盖顶部任务菜单和左下账户菜单，共 6 张深色像素基线；顶部菜单检查分组、锚点与未支持入口缺席，账户菜单检查真实额度与未支持入口缺席；
- 设置中心：真实 `SettingsPage` 在三个目标尺寸各 1 张深色像素基线，检查具体配置项搜索、空结果、当前栏目语义、未支持入口缺席和无横向溢出；
- 200%：三个 viewport 各执行一次空工作台基本几何检查，验证无横向溢出、标题与侧栏可见、composer 仍位于 viewport 内；该组不生成像素基线；
- 当前像素基线文件共 42 张，Playwright 用例实例共 45 个；
- 基线位于 `tests/visual/__screenshots__/` 下各对应 spec 的快照目录；
- `pnpm test:visual` 用于回归，`pnpm test:visual:update` 只用于人工确认后的基线更新。

深色主题在不同运行间仅出现窗口底部 12px 原生圆角的 Chromium 抗锯齿波动。测试允许最多 100 个差异像素；当前波动为 34–68 个阈值像素，内容区仍按像素比较。

## 相对参考图的当前结果

- 品牌保持 Sunsetz；不复制 Codex 名称或未支持入口。
- 侧栏已抽离为 `SidebarNavigator`；项目披露、项目选择和任务选择使用分离的原生按钮语义，任务支持 Enter / Space，当前项和焦点状态可被识别。
- 任务预览在 450ms 停留后读取有界、脱敏的最近可见摘要；键盘聚焦立即显示等价内容。项目预览只展示当前已有项目数据，不提前伪造 Git 状态。
- 项目行不再使用 coral/orange 选中或焦点边框；键盘聚焦保留中性可见描边。
- 顶部任务菜单使用项目图标、按钮展开状态和中性焦点面，真实动作按危险性与语义分组；未实现的新窗口、侧边任务和分享不显示。
- 左下账户菜单以真实账户和额度为首层信息，保留设置、主题和登录/退出；宠物、支持和更新检查等未实现入口不显示。
- 侧栏或资源面板关闭后，焦点回到对应顶部栏按钮；资源面板内容随关闭卸载，会话中栏滚动节点保持挂载。
- `HostCapabilities v2` 只让显式 `available` 的入口进入界面；未知或不可用能力保持隐藏。
- 当前提交重新构建的 macOS 调试 `.app` 已在 3024×1964 Retina 屏幕（`backingScaleFactor=2.0`）确认侧栏/资源面板关闭后焦点返回对应顶部栏按钮、资源内容从辅助功能树卸载、侧栏可用 Space 重开且面板无重叠；既有原生证据还确认项目选中态无 coral/orange 边框。
- Windows CI 使用真实 Tauri 窗口和 WebView2 CDP 检查初始窗口位于系统工作区内、资源面板打开/卸载、触发器焦点恢复及侧栏 Space 重开，并上传 `resources-open.png` 与 `native-window.png`；该证据不替代 Windows 实机缩放和辅助功能手测。
- composer 已从旧 Grok/Lobe 多 chip 布局改为三层结构，底栏不再挤成窄列。
- 900×600 的侧栏保持在布局内，composer 的左右边界均被断言位于 main 内，不再出现输入器控件被侧栏覆盖。
- 新任务项目条只有内部项目按钮响应，静态外层不再整块漂浮。
- 计划模式位于访问权限右侧，访问菜单选择后关闭；按钮悬停切换为圆圈叉并可原位退出。
- 加号菜单与 `/` 命令面板语义分离。
- 模型菜单只显示 Runtime 模型与 capability 声明的 effort；无真实 speed 时隐藏。
- 上下文悬停/聚焦先显示紧凑摘要，点击再打开详情；无精确容量时显示未知，不估算。
- 历史工具行通过 `ActivityTimeline` 保留；旧未知工具使用 generic 安全摘要。
- Agent 提问与计划确认使用底部 `AskUserDock`，不再使用居中模态框。
- 计划在消息流中显示中性 `PlanArtifactCard`，可进入右侧只读全文；只有底部 `AskUserDock` 显示“计划待审阅”并提交批准、修改或放弃，资源面板不再重复决策。
- 设置中心使用真实栏目注册表；侧栏为中性选中面，内容卡片移除装饰性渐变和厚阴影，搜索“默认权限”等配置项可以定位栏目，语音和电脑控制等未完成入口不进入导航。
