## 不可推断项

- 截图没有证明的 Host 命令、云服务、计费规则和权限范围不作为实现依据。
- 参考产品的图标、快捷键、菜单名称和信息架构不直接复制。
- macOS 可见行为不能自动视为 Windows 已支持。
- 设置截图中的栏目只有在 Sunsetz 对应后端能力完成后才能进入导航。
